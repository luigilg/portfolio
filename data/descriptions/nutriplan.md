# O Nutriplan é um sistema de acompanhamento de **saúde e bem-estar**, destinado a dois tipos de usuário:

- **Profissional/Nutricionista**: 
    - Visualização e criação de planos alimentares.
    - Controle de pacientes com atribuição de planos alimentares e acompanhamento de progresso de peso.
    - Visualização e criação de receitas alimentares.

- **Paciente/Usuário comum**: 
    - Visualização de planos alimentares criados especialmente para si (por geração automática ou por um profissional).
    - Acompanhamento de progresso de peso com metas.
    - Visualização de receitas alimentares.
    - Criação de grupos para acompanhar progresso com amigos, podendo definir data limite para motivação.

Esse projeto foi realizado em equipe com mais 3 colegas em 2025, para o Trabalho de Conclusão de Curso (TCC). 
*Fui responsável por **quase todo o desenvolvimento:***
- Criação completa do frontend.
- Grande parte do backend.
- Integração completa do backend com frontend.
- Criação de todo o design do sistema: logotipo, páginas, componentes (botões, inputs, modais, cards, menus, gráficos, etc.)


## Tecnologias Utilizadas

- **Backend:** Node.js (Express)
- **Frontend:** Vue.js com Nuxt e TailwindCSS
- **Banco de dados:** MySQL

## Funcionalidades

- Criação de planos alimentares customizados para o objetivo e restrições alimentares do usuário
- Controle de pacientes para profissionais com criação de planos e receitas
- Acompanhamento de progresso de peso com metas 
- Disponibilização de diversas receitas alimentares saudáveis
- Grupos para acompanhar progresso com amigos, podendo definir data limite para motivação
- Interface amigável e responsiva
